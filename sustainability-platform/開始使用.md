# 整包使用說明

本包包含前端原始碼、已建置網頁、FastAPI 後端、套件鎖定檔及測試。不包含任何真實 API 金鑰。

## Windows

1. 安裝 Python 3.12 或更新版本，安裝時勾選加入 PATH。
2. 解壓縮整包，進入 `sustainability-platform`，執行 `setup.bat` 安裝依賴。
3. 用文字編輯器開啟 `.env`，在 `SUSTAINABILITY_API_KEY=` 後填入你的 OpenAI API Key，儲存。
4. 執行 `start.bat`，保持命令視窗開啟。瀏覽器輸入 `http://127.0.0.1:8000`。
5. 進入「報告摘要」或「未來方針建議」，上傳 PDF，點選生成。完成後可各自下載 Markdown。

Windows 套件會安裝在 `%LOCALAPPDATA%\CYCU-ESG\venv`，避免下載資料夾名稱過長造成安裝失敗。專案本身可留在原位置；不用移動或刪除網頁程式碼。

## macOS／Linux

安裝 Python 3.12 或更新版本，在解壓後的 `sustainability-platform` 目錄執行：

```bash
bash setup.sh
```

編輯 `.env` 填入金鑰後，執行：

```bash
bash start.sh
```

瀏覽器輸入 `http://127.0.0.1:8000`。這是你自己電腦的本機網址。

## API 設定

```dotenv
SUSTAINABILITY_API_KEY=在這裡填入你的OpenAI金鑰
OPENAI_MODEL=gpt-4.1-mini
```

金鑰僅由後端讀取。ChatGPT 訂閱不包含 API 費用，需要 OpenAI API 帳號有可用額度。更換金鑰或模型後需重新啟動後端。

如果你要接的是已部署的後端網址，而不是在本機啟動，請見 `frontend/README.md` 的 `VITE_API_BASE_URL` 設定。

## 包含的功能

- 摘要與建議方針兩個頁面，沿用提供的前端設計。
- 一次分析回傳兩份獨立文件，可分別顯示與下載 Markdown。
- PDF 上限 10 MB、300 頁、100,000 擷取字元；掃描報告須先 OCR。
- 金鑰缺失、文件格式錯誤及 API 請求失敗會顯示提示。

已附 `frontend/local-dist`，直接使用成品不需要 Node.js。若要修改前端，需 Node.js >=22.12，修改後在 `frontend` 執行 `npm ci`、`npm run build`，再重新啟動後端。

目前是本機開發版，尚未加入登入與速率限制；CSV／XLSX 圖表頁仍為原本的展示。AI 生成內容需對照原報告核閱。本包的自動測試已驗證串接流程，尚未以真實金鑰驗證生成品質。

`.env` 包含你的金鑰，請勿上傳 GitHub、傳給他人，或放到前端。
